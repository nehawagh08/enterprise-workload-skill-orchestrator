# Stakeholders and User Roles

## 1. Employee

The employee is responsible for executing assigned tasks.

### Capabilities

* View assigned tasks
* Update task status
* View workload
* Manage skill profile
* Define learning goals
* View performance information
* Receive notifications

---

## 2. Team Lead

The Team Lead manages task allocation within a team.

### Capabilities

* View team members
* View team workload
* Create tasks
* Review recommendations
* Assign tasks
* Override recommendations
* Monitor team skill gaps

---

## 3. Engineering Manager

The Engineering Manager is responsible for workforce planning across one or more teams.

### Capabilities

* View workforce capacity
* Analyze workload distribution
* Review AI recommendations
* Monitor organizational skill gaps
* Review team performance
* Analyze project resource requirements

---

## 4. Project Manager

The Project Manager manages project-level resource requirements.

### Capabilities

* Create projects
* Define project skill requirements
* View available resources
* Identify resource shortages
* Monitor project capacity

---

## 5. System Administrator

The administrator manages the platform itself.

### Capabilities

* Manage users
* Manage roles
* Manage departments
* Configure system settings
* Configure recommendation weights
* View audit logs
* Manage system access

---

## 6. AI Recommendation Engine

The recommendation engine is a system component rather than a human user.

It evaluates:

* Task requirements
* Employee skills
* Workload
* Availability
* Experience
* Performance
* Learning goals

and generates ranked employee recommendations.

## 7. External Systems

Future integrations may include:

* Jira
* ServiceNow
* GitHub
* Enterprise identity providers
* Learning management systems
